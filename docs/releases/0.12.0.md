# 0.12.0：独立运行与双模式

Minecraft **1.21.1** · NeoForge **21.1.265** · Java **21**。这是预览版，客户端与房主或服务端请使用相同版本。旧世界升级前保留备份。

[下载模组](https://github.com/vdjango/lunar-dread/releases/download/v0.12.0/lunar-dread-0.12.0.jar) · [十六月相 GIF 图集](../images/moons/README.md) · [下载发帖动图素材](https://github.com/vdjango/lunar-dread/releases/download/v0.12.0/lunar-dread-0.12.0-moon-gifs.zip)

月魇现在可只安装本模组运行，不再要求 Enhanced Celestials、Stellar View、Zombies Break & Build、The Hordes 或配套数据包。这四个模组保留可选兼容。

- **概率模式**：独立安装默认启用，每晚35%概率抽取特殊月相，无天数上限。可设置开局保护、同类月相间隔、固定强度、巨月概率和各月相权重。
- **百日模式**：五天一周，前五天准备，第十天起每五天血月，之后两晚休整，第100天巨月；百日结束后停止自然事件。
- **整合包兼容**：百日围城继续使用现有数据包的百日进度。切换为概率模式时暂停数据包的百日调度，避免两套事件同时运行。
- **内置显示与收益**：原版天空支持月色、血月脉动与巨月；无需外部月相模组即可获得蓝月幸运和丰收月饥饿补充。
- **存档保存**：每日月相、随机种子和血月次数保存到世界，重启不会重复抽取。切换模式保留日期。
- **说明书**：独立安装发放对应求生手册，移除不适用的整合包前置说明。
- **预览素材**：每种月相各一张独立实机 GIF，另附巨月形态，共17张；提供总览图和打包下载。

管理员命令：

```text
/lunardread mode
/lunardread mode probability
/lunardread mode hundred_days
```

中文配置示例：[lunar_dread-server.toml](../../examples/lunar_dread-server.toml)。独立百日模式使用内置日历、补给和有限额的原版僵尸增援；整合包中的其他模组内容仍属于整合包。

验证：只安装月魇及隔离测试夹具的 NeoForge 21.1.265 服务端，覆盖两种模式、概率边界、事件间隔、百日结束和重启保存；纯净客户端实际进入世界，确认普通月、血月、巨月和倒悬月渲染。
